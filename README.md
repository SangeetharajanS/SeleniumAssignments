# Selenium Automation Assignments

Hands-on automation assignments completed as part of Test Leaf's 
REST API Automation certification program.

## Stack
Core Java, Selenium WebDriver, API Client integration, JDBC/Database connectivity

## What's inside
- assignmentsWeek1/ — Core Java fundamentals and Selenium WebDriver browser setup
- assignmentsWeek2/ — Selenium-based form automation and CRUD scenarios 
  (account creation, lead creation, library management)
- assignmentWeek3/ — Web element handling (buttons, checkboxes, radio buttons, 
  text fields), API client calls, and database connectivity using Java

## Note
Coursework project from Test Leaf's automation program. Currently extending 
with REST Assured, TestNG, and CI/CD tooling as part of ongoing upskilling.
